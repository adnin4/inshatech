## 🚨 ১. লাইভ সাবপেজ ৩০৮ লুপের প্রকৃত কারণ (Root Cause Analysis):

* **শনাক্তকৃত সমস্যা:**
  * রিপোজিটরিতে একই সাথে রুট ফাইল `store.html`, `marketplace.html`, `portal.html`, `admin.html` এবং সাবডাইরেক্টরি `store/index.html`, `marketplace/index.html` ইত্যাদি বিদ্যমান ছিল।
  * ক্লাউডফ্লেয়ার পেজেসের অটোমেটিক ক্যানোনিকালাইজেশন ইঞ্জিন `/store.html` রিকোয়েস্টকে `/store`-এ ৩০১/৩০৮ রিডাইরেক্ট করে।
  * একই নামের সাবডাইরেক্টরি `store/` থাকায় ক্লাউডফ্লেয়ার পেজেস ইন্টারনাল ডিরেক্টরি রেজোলিউশন লুপে পড়ে একটি পারমানেন্ট ৩০৮ রিডাইরেক্ট লুপ রিটার্ন করছিল (`Location: /store`).
