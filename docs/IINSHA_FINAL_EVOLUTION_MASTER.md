## ⚖️ 2. Dynamic Risk-Based Permission Engine

Instead of static permissions based only on tool names, the runtime dynamically evaluates risk for every action:

$$\text{Final Risk Score} = \text{Agent Base Risk} + \text{Customer Risk} + \text{Financial Risk} + \text{Data Risk} + \text{Blast Radius} - \text{Confidence}$$

* **Score 0–19 (LOW)**: Automatically executed (L0 Read / L1 Draft).
* **Score 20–44 (MEDIUM)**: Policy-checked execution (L2 Low-Risk Execution).
* **Score 45–69 (HIGH)**: **Halted for Mandatory Owner 1-Click Approval** (L3 External / L4 Financial Gate).
* **Score 70–100 (CRITICAL)**: **Hard Blocked** (L5 Root Restricted).
