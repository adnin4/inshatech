# IINSHATECH MASTER CONTROL STUDIO — USER & ADMIN GUIDE

## 1. Accessing the Control Studio
1. Open the website: `https://inshatech.pages.dev/`
2. Click the top navbar button: **`🎛️ Control Panel (Auth)`**
3. The Admin Auth Gateway Card will appear.
4. Enter default credentials (`admin@iinsha.ai` / `admin123`) and click **`🔓 Authenticate & Open Studio`** or click **`⚡ 1-Click Master Super Admin Unlock`**.

---

## 2. Admin Modules Overview
The Control Studio features 50 management modules:
- **Service Catalog**: Create, Edit, Duplicate, Archive, and Publish AI Services and package tiers.
- **Universal Content**: Dynamically edit hero titles, subtitles, CTA texts, and WhatsApp numbers.
- **Affiliate Ledger**: Review PartnerStack-grade referrals, approve payouts, and set commission rates.
- **Order Management**: Monitor order states (`draft` -> `paid` -> `completed`).
- **Payment Gateways**: Enable/Disable bKash, Nagad, Stripe, Bank Wire.
