4. ROLLBACK AND DISASTER RECOVERY PROCEDURES
--------------------------------------------------------------------------------
A. Instant Edge Rollback (Under 60 Seconds)
If an edge regression or defect is detected post-deployment:

Method 1: Wrangler Instant Redeployment of Previous Stable SHA
1. Find previous stable commit SHA:
   git log -n 5 --oneline
2. Checkout previous stable commit:
   git checkout <stable-commit-sha>
3. Deploy immediately:
   npx wrangler pages deploy . --project-name=inshatech --branch=master
4. Return to master branch:
   git checkout master

Method 2: Cloudflare Dashboard 1-Click Rollback
1. Log into Cloudflare Dashboard: https://dash.cloudflare.com/
2. Navigate to Workers & Pages -> inshatech -> Deployments.
3. Locate the previous healthy deployment ID.
4. Click the three dots (...) next to the deployment -> "Rollback to this deployment".
5. Rollback is applied globally across Cloudflare edge within 30 seconds.

B. Git Tree Rollback Protocol
Never execute destructive 'git push --force' or 'git reset --hard' on public branches.
To revert a problematic commit:
1. Revert commit cleanly:
   git revert <bad-commit-sha> -m 1
2. Run test battery:
   npm test
3. Deploy new revert commit:
   npx wrangler pages deploy . --project-name=inshatech --branch=master
