## 🎯 ১. Google Search Console Verification (HTML Tag Method)

In your `index.html`, we have already pre-configured the `<head>` to accept your Google Search Console verification code instantly.

When you open [Google Search Console](https://search.google.com/search-console):
1. Click **Add Property** -> Select **URL prefix** -> Enter: `https://inshatech.pages.dev/`
2. Under **Other verification methods**, choose **HTML tag**.
3. Copy the `content="..."` code and you are verified instantly!
4. Go to **Sitemaps** on the left menu -> Enter `sitemap.xml` -> Click **Submit**.

## 🚀 ২. Connecting a Custom Domain (inshatech.com / inshatech.ai) on Cloudflare Pages

To give your brand the highest global SEO authority:
1. In your Cloudflare Dashboard -> Go to **Workers & Pages** -> Select **inshatech**.
2. Click the **Custom domains** tab -> Click **Set up a custom domain**.
3. Enter your domain (e.g., `inshatech.com`).
4. Cloudflare will automatically configure the SSL certificate and DNS routing in 60 seconds with zero downtime!
